# Pwn-Tools-Custom

Small custom tools I've built to speed up recurring tasks in binary exploitation / CTF pwn challenges. Each tool lives in its own folder with its own README.

## Tools

| Tool | Description |
|---|---|
| [`libc-identify`](./libc-identify) | Identifies and downloads the exact remote libc build from a single leaked symbol address, via the `libc.rip` API. |

More tools will be added here as I build them.
